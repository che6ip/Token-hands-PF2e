# PF2e: Руки на токене

Дополнение к базовому модулю [**«Руки на токене»**](https://github.com/che6ip/Token-hands/tree/main), которое учит его работать с **Pathfinder 2e**.

Сам по себе базовый модуль ничего не знает о предметах и системах — он только рисует слоты рук. Этот модуль объясняет ему, что именно персонаж или NPC держит в руках в Pathfinder 2e. **Без него база не сможет показать руки в этой системе.**

## Что показывает

- Оружие, щиты и другие предметы, которые персонаж держит в руках.
- Двуручное оружие — иконка справа и затемнённая копия слева.
- Если занята только одна рука, в свободном слоте может отображаться безоружная атака актёра.
- Если в руках ничего нет, слоты не рисуются — токен остаётся чистым.

## Как это выглядит в игре

- Иконки появляются в нижних углах токена.
- ЛКМ по иконке открывает карточку предмета.
- Размер иконок и остальные общие настройки берутся из базового модуля.
- Если у токена виден HP-бар, иконки поднимаются выше и не закрывают его.

## Требования

- Foundry VTT 13–14
- Система **Pathfinder 2e**
- Включённый базовый модуль **«Руки на токене»** (`token-hands`)

## Установка

1. Включите базовый модуль **«Руки на токене»**.
2. Включите этот модуль.
3. Перезагрузите мир.

Если базовый модуль не включён, этот модуль работать не будет — ему просто некуда передавать данные о руках.
